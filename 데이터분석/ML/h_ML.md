# 스케일링
**StandardScaler.fit_transform(X_train)**는 우리 반 친구들의 키와 수학 성적을 모두 0점부터 1점 사이의 점수로 바꿔주는 **'기준'**을 만드는 과정이에요.
**StandardScaler.transform(X_test)**는 다른 반 친구들의 키와 수학 성적도 우리가 만든 **'기준'**에 맞춰 똑같이 바꿔주는 과정이죠.

스케일링은 이렇게 단위가 다른 값들을 모두 똑같은 기준으로 맞춰주는 것이에요.
왜 이렇게 하냐면, 컴퓨터가 데이터를 분석할 때, 큰 숫자에만 영향을 받지 않고 모든 데이터들을 공평하게 고려할 수 있게 하기 위해서예요.

# 독립 변수와 종속 변수
독립 변수(Independent Variable): 결과를 결정하는 원인이 되는 데이터입니다.
X_train : 키, 나이, 클래스 등

종속 변수(Dependent Variable): 독립 변수에 의해 결정되는 결과 데이터입니다.
y_train: 생존 여부

# K-NN: 데이터 포인트 간의 거리를 기반으로 작동
* 거리 기반 모델은 왜 스케일링이 필요
스케일이 큰 특성이 스케일이 작은 특성을 압도하여 모델이 올바른 이웃을 찾지 못하고 예측 성능이 저하됩니다.
스케일링: 스케일링은 모든 특성들이 동일한 값 범위를 갖도록 데이터를 변환하는 전처리 과정

- 주의사항
1. 데이터 스케일링: 범위가 큰 특성이 거리 계산에 지배적인 영향을 미치게 됩니다. 예를 들어, 몸무게(kg)와 키(cm) 데이터가 있을 때, 몸무게의 범위가 키보다 훨씬 작다면, 모델은 키의 변화에만 민감하게 반응할 수 있습니다.
따라서 K-NN을 사용하기 전에는 StandardScaler나 MinMaxScaler와 같은 도구를 사용해 모든 특성의 스케일을 동일하게 맞춰주는 데이터 스케일링 작업이 필수적

2. K는 새로운 데이터 포인트를 분류할 때 고려할 이웃의 개수입니다. 이 K 값에 따라 모델의 성능이 크게 달라질 수 있습니다.
일반적으로 K는 홀수로 설정하여 다수결 투표 시 동률이 발생하는 것을 피합니다. 최적의 K 값은 교차 검증(cross-validation)을 통해 찾는 것이 가장 좋습니다.

3. 데이터의 특성(차원)이 많아질수록 데이터 포인트 간의 거리가 모두 비슷해지는 현상이 발생합니다. 고차원 공간에서는 '가장 가까운 이웃'을 찾는 의미가 퇴색되어 K-NN의 예측 성능이 급격히 떨어집니다.

4. 적절한 이웃의 수(K)를 정하는 방법
