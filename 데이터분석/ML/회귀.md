### 지도학습 vs 비지도학습
지도학습: 정답 모델 학습 (ex) 분류, 회귀
비지도학습: 정답 없음, 패턴, 구조 학습

# 분류: 다수결 -> 많은 클래스 선택
# 회귀: 이웃 값 평균 -> 예측값 생성

하이파라미터 K: 가장 가까운 이웃의 수
작다: 훈련 데이터 노이즈에 민감 → 과대적합
크다: 주변 데이터까지 포함 → 과소적합

# K-NN: 데이터 포인트 간의 거리를 기반으로 작동
* 거리 기반 모델은 왜 스케일링이 필요
스케일이 큰 특성이 스케일이 작은 특성을 압도하여 모델이 올바른 이웃을 찾지 못하고 예측 성능이 저하됩니다.
스케일링: 스케일링은 모든 특성들이 동일한 값 범위를 갖도록 데이터를 변환하는 전처리 과정

- 주의사항
1. 데이터 스케이링: 범위가 큰 특성이 거리 계산에 지배적인 영향을 미치게 됩니다. 예를 들어, 몸무게(kg)와 키(cm) 데이터가 있을 때, 몸무게의 범위가 키보다 훨씬 작다면, 모델은 키의 변화에만 민감하게 반응할 수 있습니다.
따라서 K-NN을 사용하기 전에는 StandardScaler나 MinMaxScaler와 같은 도구를 사용해 모든 특성의 스케일을 동일하게 맞춰주는 데이터 스케일링 작업이 필수적

2. K는 새로운 데이터 포인트를 분류할 때 고려할 이웃의 개수입니다. 이 K 값에 따라 모델의 성능이 크게 달라질 수 있습니다.
일반적으로 K는 홀수로 설정하여 다수결 투표 시 동률이 발생하는 것을 피합니다. 최적의 K 값은 교차 검증(cross-validation)을 통해 찾는 것이 가장 좋습니다.

3. 데이터의 특성(차원)이 많아질수록 데이터 포인트 간의 거리가 모두 비슷해지는 현상이 발생합니다. 고차원 공간에서는 '가장 가까운 이웃'을 찾는 의미가 퇴색되어 K-NN의 예측 성능이 급격히 떨어집니다.

4. 적절한 이웃의 수(K)를 정하는 방법

# 로지스틱 회귀: 데이터가 특정 범주에 속할 확률을 0과 1 사이의 값으로 예측하고, 이 확률을 기준으로 범주를 결정

선형 방정식 z 를 계산 후,
이진분류 → 시그모이드 함수(sigmoid)
다중분류 → 소프트맥스 함수(softmax)
출력은 확률 (0~1), 확률이 가장 큰 클래스로 예측

함수식을 구한 결과값을 가지고 *분류하는 모델
수식 -> 수식결과 z -> 0~1 확률

수식결과 즉 값은 z라고 함
물고기 종류가 3개면, 종류별로 식이 3개, z도 3개

decision_function -> 
softmax함수 넣어서 확률로 바꾸기
-> predict_proba

(ex) kaggle "fake-news-dataset"
