# 따옴표 사용방법
따옴표O: '문자', '1990-01-01' | 따옴표X: 컬럼명

IN연산자, LIKE연산자 차이: 

항목	       IN 연산자	      LIKE 연산자
-------------------------------------------------------
사용 목적|정확한 값 목록 비교      |문자열 패턴 매칭
비교 방식|값이 목록에 포함되는지    |문자열이 패턴과 일치하는지
예시|WHERE id IN (1, 2, 3)|WHERE name LIKE 'A%'
성능|인덱스 활용 가능, 일반적으로 빠름|패턴 매칭으로 인해 느릴 수 있음
